# Роскомнадзор: черновики уведомлений и регламент при утечке

Три документа в одном файле: черновик уведомления об обработке персональных
данных (ст. 22 152-ФЗ), черновик уведомления о трансграничной передаче
(ст. 12) и внутренняя памятка на случай утечки (ст. 21 ч. 3.1).

Оба уведомления подаются **до начала** соответственно обработки и передачи —
то есть до первого живого пользователя. Форма — на портале РКН
(pd.rkn.gov.ru), подача электронно через Госуслуги от лица оператора;
черновики ниже повторяют поля формы, чтобы заполнение заняло полчаса, а не
день. Всё в квадратных скобках появляется после регистрации ИП.

Подаётся отдельно от первого, тоже заранее. По странам:

| Поле             | Что писать                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Получатель       | Google Ireland Ltd. / Google LLC — сервис Firebase (Cloud Firestore, Storage, Authentication), ЦОД региона europe-west3 (Франкфурт) |
| Категории данных | все, перечисленные в уведомлении об обработке (хранение базы сервиса)                                                               |
| Цель             | хранение и обработка данных сервиса                                                                                                 |
| Основание        | договор с субъектом (пользовательское соглашение); условия обработки — Google Cloud Data Processing Addendum                        |

**США** (адекватную защиту не обеспечивают — РКН вправе запретить в течение
10 рабочих дней, ждать ответ перед запуском):

| Поле             | Что писать                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Получатель       | Expo (650 Industries, Inc.) — сервис доставки push-уведомлений                                                         |
| Категории данных | идентификаторы устройств (push-токены); тексты уведомлений, которые могут содержать имя пользователя и название заявки |
| Цель             | доставка уведомлений о ходе заявок                                                                                     |
| Основание        | ст. 12 ч. 8 п. 3 — исполнение договора, стороной которого является субъект                                             |

Запасной план, если РКН откажет по США: обезличить тексты пушей (без имён и
названий заявок — «Новое предложение по вашей заявке») — тогда в США уходит
только технический токен, и передача ПД практически прекращается. Правится
в одном файле: `functions/src/index.ts` (тексты `pushTo`).

## 3. Памятка: если случилась утечка

Обязанность из ст. 21 ч. 3.1 152-ФЗ; штрафы за сами утечки с 30.05.2025
существенные, за молчание — отдельный состав. Часы отсчитываются от момента,
когда об инциденте узнал оператор.

1. **Сразу**: закрыть дыру (обычно — `npm run rules:deploy` с исправленными
   правилами; в крайнем случае «выключить» приложение сменой правил на
   `allow read, write: if false`). Зафиксировать время и что произошло.
2. **До 24 часов**: первичное уведомление в РКН через форму на портале:
   что случилось, какие категории данных и сколько субъектов
   предположительно затронуто, ответственный и его контакты.
3. **До 72 часов**: результаты внутреннего расследования: причина, полный
   состав утёкшего, принятые меры. Источники для расследования в проекте:
   коллекция `audit` (какие операции шли), консоль Firebase (доступы),
   `rules:check` (какие правила стояли в бою).
4. Уведомлять затронутых пользователей закон напрямую не требует, но при
   утечке адресов — стоит: сервис держится на доверии к тому, что адреса
   видят только проверенные мастера.

Незакрытый вопрос для юриста: порог, с которого инцидент считается
«неправомерной передачей» (например, один адрес, показанный не тому
мастеру из-за ошибки правил, — уже инцидент?).
