# Письма Firebase Auth: тексты и настройка

Сброс пароля и смена почты — единственные письма, которые сервис шлёт от
своего имени за пределами приложения. Стандартные шаблоны Firebase выглядят
безлико и пугают людей, которые ничего не заказывали. Здесь — готовые
тексты в голосе Домио и куда их вставить.

Шаблоны меняются **только в консоли** (API для этого нет):
**Firebase Console → Authentication → Templates**.

## Известное препятствие: «Email template updates are currently unavailable»

Красный баннер на странице Templates — не ошибка, а замок Google против
фишинга: новым проектам на бесплатном тарифе Spark редактировать письма
не дают. Разблокируется так:

1. **Перевести проект на тариф Blaze** — он всё равно обязателен по плану
   релиза: без него не деплоятся Cloud Functions и не работает Secret
   Manager для ключей ЮKassa. После перехода редактирование шаблонов,
   как правило, открывается.
2. Если после Blaze замок остался — тикет в
   [Firebase Support](https://firebase.google.com/support/troubleshooter/contact)
   (ссылка есть и в самом баннере) с просьбой включить редактирование
   шаблонов; с Blaze это полноценное обращение, отвечают за день-два.

Пока замок висит, всё равно доступны две настройки, которые улучшают
даже стандартные письма, — «Public-facing name» и «Support email»
(см. ниже): «Reset your password for Домио» вместо голого идентификатора
проекта.

Дальний путь для полного контроля (когда появится свой домен): не
пользоваться встроенной отправкой вовсе — генерировать ссылку сброса на
сервере (`generatePasswordResetLink` в Admin SDK) и слать собственное
письмо из Cloud Function через свой почтовый сервис.

## Сначала — три общих настройки

1. **Язык шаблонов**: на вкладке Templates внизу «Template language» →
   карандаш → **Русский**. Это переключит и системные тексты Firebase.
2. **Публичное имя проекта**: Project settings → General → Public settings →
   Public-facing name → **Домио**. Его подставляет плейсхолдер `%APP_NAME%`
   и показывает страница подтверждения после клика по ссылке.
3. **Support email** там же — когда появится support-адрес
   (см. OPERATOR-SETUP, шаг 2; в `components/legal.ts` он же `CONTACT`).

В каждом шаблоне:

- **Sender name**: `Домио`
- **From**: оставить `noreply@domio-7ad1c.firebaseapp.com` — свой домен
  подключается позже через верификацию DNS (Templates → пункт
  «Customize domain»), тогда письма перестанут попадать в спам чаще.
- **Reply-to**: support-адрес, когда появится. До этого — пусто.

Плейсхолдер `%LINK%` обязателен — без него консоль шаблон не сохранит.

## Сброс пароля (Password reset)

**Тема:** `Домио — сброс пароля`

```
Здравствуйте!

Вы попросили сбросить пароль в Домио для аккаунта %EMAIL%.

Придумать новый пароль: %LINK%

Ссылка действует ограниченное время. Если это были не вы — просто не
открывайте её: пароль останется прежним, и в аккаунт никто не попадёт.

— Домио, мастер по дому под рукой
```

## Подтверждение адреса (Email address verification)

Приложение пока не требует подтверждения почты, но шаблон лучше подготовить
сейчас: если включим — письмо уже будет говорить по-русски.

**Тема:** `Домио — подтвердите почту`

```
Здравствуйте!

Остался один шаг: подтвердите, что %EMAIL% — это вы.

Подтвердить почту: %LINK%

Если вы не регистрировались в Домио, просто удалите это письмо — ничего
не произойдёт.

— Домио, мастер по дому под рукой
```

## Смена адреса (Email address change)

Это письмо уходит на **старый** адрес, а `%LINK%` **отменяет** смену —
поэтому текст должен объяснять, что делать, если почту сменил не владелец.

**Тема:** `Домио — почта аккаунта изменена`

```
Здравствуйте!

Почта вашего аккаунта Домио изменена на %NEW_EMAIL%.

Если это были вы — всё в порядке, письмо можно закрыть.

Если нет — верните прежний адрес по ссылке и сразу смените пароль: %LINK%

— Домио, мастер по дому под рукой
```

## Чего здесь нет намеренно

- **SMS verification** (вкладка рядом) — не трогаем: коды входа по телефону
  шлёт собственная функция `phoneAuth`, а не Firebase Phone Auth, и текст
  СМС задаётся в `functions/src/phoneAuth.ts`.
- **Multi-factor enrollment** — MFA в приложении нет.
- Смена **Action URL** — стандартная страница после клика устраивает;
  свой адрес имеет смысл вместе со своим доменом отправителя.
