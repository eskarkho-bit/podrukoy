# План выхода в App Store

Составлен 21.08.2026 по состоянию ветки `feature/marketplace-and-verification`.
Оценка готовности: **~60%**. Код продукта готов на ~85–90%, но между ним и
магазином стоят три блока работы, которых в коде не видно: боевая
инфраструктура Firebase, юридика по 152-ФЗ и сама публикация.

Правило работы с планом: сделали пункт — ставим галочку и коммитим. Пункты
внутри этапа идут в порядке выполнения; этапы 1–3 можно вести параллельно.

## Что уже готово (и почему это много)

- Полный цикл заявки: создание → предложения мастеров → выбор → работа →
  подтверждение → отзыв. Перехват чужих предложений невозможен по схеме данных.
- Проверка мастеров: анкета, фото лица, телефон, привязка карты через ЮKassa
  (рубль туда-обратно), ручная модерация, сводка для модератора.
- Чат клиент–мастер после выбора исполнителя, пуш-уведомления (код готов).
- Удаление аккаунта из приложения с обезличиванием заявок — требование обоих
  магазинов выполнено.
- Согласия с версионированием, отдельное согласие на биометрию, отзыв согласия.
- 103 теста правил Firestore + 47 тестов функций + 69 тестов компонентов, CI.
- EAS-проект заведён, expo-updates настроен, иконки и фирменный стиль есть.

## Советы

1. **Начинайте с этапа 3 сегодня.** Регистрация ИП, юрист и Роскомнадзор —
   недели, всё остальное — дни. Технические этапы 1–2 делаются параллельно.
2. **Вопрос локализации данных решите до, а не после публикации.** Если юрист
   скажет «переносить в РФ», это смена бэкенда — лучше знать это раньше, чем
   после жалобы.
3. **Не открывайте все города сразу.** Маркетплейс жив, когда на заявку
   отвечают. Один город с десятком мастеров лучше республики с нулём.
4. **TestFlight-период не сжимайте.** Пуши, камера и платёж проверяются
   только на живом устройстве с боевыми функциями — это первый момент, когда
   вся цепочка соберётся вместе.
5. **Ревью Apple**: приложения с «проверкой людей» и платежами смотрят
   внимательно. Записка ревьюеру про то, что рубль возвращается и оплата работ
   идёт вне приложения между сторонами, снимет большинство вопросов заранее.
